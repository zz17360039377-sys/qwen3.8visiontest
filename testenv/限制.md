# testenv —— VLM 标注能力测试环境

本文件夹是给大模型（VLM）做标注能力测试的**封闭环境**：只有数据集和规则，
**不放任何成品代码**。测试产物一律写到 `testenv/results/` 下。

## 目录结构

```
testenv/
├── 限制.md            ← 本文件（规则）
├── datasets/          ← 测试数据集（只读！）
│   └── <数据集名>/
│       ├── images/        图片
│       ├── labels/        标签（与 images/ 同名对应：同名不同扩展名）
│       ├── classes.txt    类别表（每行一个类名，行号=类别 id）
│       ├── manifest.csv   图片↔标签对照
│       └── README.md      该数据集的来源/类别/数量说明
└── results/           ← 测试输出（自行创建 <测试名>/ 子目录）
```

## 数据集类型与标签格式

| 类型 | labels/ 内容 | 格式约定 |
|---|---|---|
| yolo-pose | `<同名>.txt` | 每行 `cls cx cy w h x1 y1 v1 … xN yN vN`，全归一化 [0,1]，v∈{0,1,2}；N 见该数据集 README |
| yolo-detect | `<同名>.txt` | 每行 `cls cx cy w h`，归一化；空行=无目标 |
| 分类 | `<同名>.txt` | 一行，内容=类别名字符串 |
| labelme | `<同名>.json` | 原始 LabelMe 格式（`shapes[].label` + `points`） |

所有数据集入库存放前已通过校验：图片可解码、标签 token 数/坐标范围/类别 id 合法、内容级去重。

## 限制（必须遵守）

1. **数据集只读**：不得移动、重命名、删除、修改、增删 `testenv/datasets/` 下任何文件。
2. **输出隔离**：所有测试产物写到 `testenv/results/<测试名>/`；不得写入数据集目录，不得写回项目代码目录。
3. **类别表**：`classes.txt` 行号即类别 id（YOLO 标签首列）。
4. **提示词自备**：本环境不提供提示词与推理代码。
5. **测试环境内不放任何成品代码。**

## 测试输出格式（规范，评测脚本按此解析）

对**每一张**要测的图片，在结果目录写一个与图片同名的文本文件：

```
testenv/results/<测试名>/<数据集名>/labels/<图片stem>.txt
```

各类型的行格式（与数据集 labels/ 完全同构）：

| 数据集类型 | 每行内容 | 说明 |
|---|---|---|
| `detect_*` | `class cx cy w h` | 归一化 [0,1]；`class` 可写数字 id 或 classes.txt 里的类名 |
| `pose_*` | `class cx cy w h x1 y1 v1 … xN yN vN` | N 必须与该数据集 README 标注的关键点数一致；v∈{0,1,2} |
| `cls_*` | 整个文件只有一行：类名字符串（或数字 id） | 如 `3` 或 `R4` |
| `labelme_*` | `class cx cy w h` | 对每个标注对象输出其最小外接框；`class` 用 json 里的 label 名 |

约定：
- 只测部分图片也可以，未提供预测的图片在评测中记为「漏标」；
- 解析失败的行会被跳过并计数，不会中断评测；
- 可选：在 `results/<测试名>/<数据集名>/notes.md` 里记录所用提示词与参数，便于复盘。

## 评测（一键）

```bash
python3 tools/eval_testenv.py --run <测试名>            # 评 results/<测试名>/ 下全部数据集
python3 tools/eval_testenv.py --run <测试名> --datasets detect_rm2025_armor,cls_armor_digit_slices
```

输出：`results/<测试名>/eval_report.md`（汇总指标）+ `eval_details.csv`（逐匹配明细）
+ `results/<测试名>/vis/<数据集>/`：**随机抽样对比页（sample_*）与全部失败样例页（fail_*）**，
绿=标准答案、红=VLM 预测；失败判定 = detect/labelme 的 FP/FN 框、pose 的漏配或关键点归一化
误差 > PCK 阈值、cls 的类名错误。`--vis` 抽样数（默认 12）、`--vis-fail-max` 失败可视化上限
（默认 200）。
指标：detect/labelme → IoU≥0.5 匹配的 Precision/Recall/F1、平均 IoU、分类别 P/R/F1；
pose → 框 IoU≥0.3 匹配后每关键点 MPJPE（px 与按框对角线归一）、PCK@0.05/0.1；
cls → 准确率 + 混淆矩阵。
